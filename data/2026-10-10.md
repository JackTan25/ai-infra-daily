### [1] [IAPRepair: In-Network Aggregation Enhanced Proactive Repair for Erasure-Coded Storage System](https://arxiv.org/abs/2610.11114)

  <summary>Details</summary>
Motivation: 纠删码以远低于全复制的存储开销提供容错，但修复丢失或处于风险中的块需要密集的跨节点数据传输。现有方案存在两类割裂：反应式修复只在故障发生后才启动，无法利用故障前的空闲带宽；主动式修复虽可提前迁移数据，却把迁移、重建与网络聚合当作松散耦合的操作分别处理。由此产生三个系统性瓶颈：接收端（receiver-side）成为拥塞点、可用带宽异构导致迁移/重建并行度受限、可编程交换机状态资源有限使网内聚合难以大规模启用。核心需求是在带宽异构条件下同时保住迁移并行度、缓解接收端瓶颈，并控制交换机的表项/状态预算。

Existing reactive repair schemes start only after a failure, while proactive schemes can move data before failure but commonly treat migration, reconstruction, and network aggregation as loosely coupled operations. As a result, receiver?side bottlenecks, heterogeneous available bandwidth, and limited programmable-switch state continue to constrain repair paral?lelism. This paper presents IAPRepair, an in-network aggre?gation enhanced proactive repair framework for erasure-coded storage. Across coding parameters, block sizes, node populations, and multiple STF-node scenarios, IAPRepair reduces repair time by at least 47.83% compared with the evaluated state-of-the-art methods. Main category: cs.DC

<details>
  <summary>Details</summary>
Motivation: MoE 模型规模化后依赖跨多设备的专家并行（EP）服务，而专家负载倾斜导致计算、通信、内存三个维度同时出现不均衡，因此现有系统普遍把负载均衡当作核心优化目标。但论文的关键观察是"均衡并非免费"：为了平衡某一维度而引入的操作（如 token 重排、冗余计算、权重搬运）本身可能既昂贵又不均衡。也就是说，均衡操作的开销可能超过其收益，单维度均衡甚至会损害端到端性能。因此需要重新定位均衡的角色。

Method: Zepp 的核心范式转换是：把均衡视为对物理资源（GPU 与 NIC）的简化约束，而非优化目标，直接以瓶颈通信为优化对象。整体是"放置—路由—执行"三阶段渐进优化，并在每次迭代中联合协调计算、token 通信与专家权重迁移以适配动态负载：1) 放置阶段：在 GPU 约束下放置专家副本，降低 token 通信量（减少跨节点 token 传输）；2) 路由阶段：在 NIC 约束下，通过 split 与 merge 原语重塑通信流，改变流量拓扑与聚合粒度；3) 执行阶段：对专家计算进行划分与调度，使计算与前述通信重叠，掩盖通信时延。三步分别对应通信量、通信形态与通信隐藏，逐层逼近最优执行。

Result: 实现并进行评测，对比 7 个 SOTA MoE 服务系统：MoE 层最高加速 6.68x；相对最快竞争基线，几何平均加速 1.86x。

Conclusion: 该工作的系统贡献在于提出"均衡即约束、通信即目标"这一新的 MoE 服务优化范式，并用放置/路由/执行三阶段机制将其落地，同时通过迭代内的计算、token 通信、专家权重迁移联合调度应对动态负载。工程影响上，它指向一个可复用的设计原则：不应盲目追求单维度均衡，而应以瓶颈通信（跨节点 all-to-all、NIC 带宽）为第一性目标，把均衡压缩为 GPU/NIC 的可行性约束。这为 EP 规模持续扩大下的 MoE 推理/服务系统提供了新的优化靶点，且方法（副本放置、通信原语重塑、通信-计算重叠）具备较强的可迁移性。

Abstract: As Mixture-of-Experts (MoE) models continue to scale, serving them increasingly relies on expert parallelism (EP) across a growing number of devices. Yet skewed expert workloads create imbalance across computation, communication, and memory, making load balancing a central optimization objective in distributed MoE serving. We observe that balance is not free: operations introduced to balance one dimension can themselves be expensive or imbalanced. This motivates us to rethink balance as a constraint rather than an optimization objective. We present Zepp, which directly optimizes the bottleneck communication in distributed MoE serving subject to simplified balance constraints on physical resources, i.e., GPUs and NICs. Zepp progressively optimizes inter-node communication across placement, routing, and execution. It first places expert replicas to reduce token communication under GPU constraints, then reshapes communication flows through split and merge primitives under NIC constraints, and finally partitions and schedules ex- pert computation to overlap the resulting communication. To adapt to dynamic workloads, Zepp jointly coordinates computation, token communication, and expert-weight movement at each iteration. Together, these designs allow Zepp to pursue the most efficient execution rather than a single-dimension balanced one. We implement Zepp and evaluate it against 7 state-of-the-art MoE serving systems, achieving up to 6.68$\times$ MoE layer speedup and a geometric mean speedup of 1.86$\times$ over the fastest competing baseline.

### [3] [PageWeaver: KV-Guided Query Unions for Sparse Attention](https://arxiv.org/abs/2610.11201)
*Zhiyuan Li,Zihan Li,Zefang Yuan,Lei Wang,Hao Wang*

Main category: cs.DC

TL;DR: PageWeaver 是一种面向动态稀疏注意力（DSA）的执行设计：利用"被选中 KV page 的亲和性"对 query 进行分组装配（regrouping），在不改变每条 query 原始 support、也不改变输出归属的前提下，让同组 query 通过 page union 共享 KV page 加载并填满 Tensor Core tile。它把"分组决策"与"执行"解耦：由有界 GPU 搜索生成 query ID，再由 ID-aware 双 CTA kernel 直接消费，避免物化重排后的 Q 张量和跨 page 部分输出。


<details>
  <summary>Details</summary>
Motivation: 动态稀疏注意力通过限制每条 query 可选的 KV page 数量（小 support）来降低理论计算量，但小 support ≠ 高效的 GPU 工作。真实瓶颈在于：单条 query 的 page 集合过小且互不重合，导致 KV page 加载无法摊销、Tensor Core tile 填充率低、kernel 呈 memory/latency-bound。跨 query 的 page 复用（nonlocal reuse）只有在"哪些 query 被分到一组"这一决策正确时才成立，因此分组质量直接决定性能。论文的动机是把这一被忽视的"执行分组"变量显式化，并给出可在线使用的低成本方案。

Method: 1) 以 selected-page affinity 为代价度量，对有界数量的 query 做 GPU 内搜索，输出重新排序后的 query ID；2) ID-aware 双 CTA（two-CTA）kernel 直接按 ID 消费结果，不物化 reordered Q tensor、不产生跨 page 的 partial output，从而保持每条 query 的原始 support 与完整 output ownership；3) 提供直接 KV-page union 实现作为对照设计研究，量化 nonlocal reuse 与 reduction 成本；4) 全链路采用 FP8 KV；5) 在 H200 上实现 Union8 配置，并对 online regrouping 与 whole-model prefill 分别测量；6) 在 B300 上做对照，识别 preparation cost 与更强 native kernel 抹平收益的场景。

Result: H200 + FP8 KV 下，Union8 在 6 组 capture 上相对实测 FlashInfer 路径取得 1.70x 几何平均完整调用加速。Online regrouping 在 5 个 64K 上下文 capture 上再降 3.26–7.66% 延迟。整模型 prefill 吞吐比测试的 native 路径高 7.88–14.36%；但增量 regrouping 收益明显更小，32K/64K 下中位增益仅 0.47–0.73%，8K 甚至出现回退。B300 对比显示部分场景中 preparation cost 加更强的 native kernel 会完全消除该优势。

Conclusion: 论文的核心价值是"分离"：把"执行分组的复用收益"与"在线利用它的完整成本"分开度量。它证明 page affinity 分组是稀疏注意力 kernel 上一个真实且可观的优化维度（kernel 级 1.70x），但也诚实地指出该收益在整模型与更新硬件上会被 amortize 或抵消。工程启示是：分组/调度层（ID 生成 + ID-aware kernel）应作为独立可插拔组件，并需按 workload（上下文长度、batch、硬件代际）决定是否开启在线重组。

Abstract: Dynamic sparse attention limits the KV pages selected by each query, but a small support does not necessarily yield efficient GPU work. Query unions share page loads and populate Tensor Core tiles; their cost depends on which queries are grouped together. We present PageWeaver, an execution design that uses selected-page affinity to assemble query groups while preserving each query's original support and complete output ownership. A bounded GPU search produces query IDs, and an ID-aware two-CTA kernel consumes them without materializing reordered Q tensors or cross-page partial outputs. A direct KV-page union implementation provides a complementary design study of nonlocal reuse and reduction cost. With FP8 KV throughout, the H200 Union8 implementation achieves a 1.70x geometric-mean complete-call speedup over the measured FlashInfer path on six captures. Online regrouping further lowers latency by 3.26-7.66% on five selected 64K-context captures. Whole-model prefill throughput is 7.88-14.36% above the tested native path; the incremental regrouping benefit is smaller, with observed median gains of 0.47-0.73% at 32K/64K and regressions at 8K. A B300 comparison identifies cases where preparation cost and a stronger native kernel remove the advantage. These results separate execution-group reuse from the complete cost of exploiting it online.

### [5] [New Contraction Bounds for Multidimensional Asymptotic Consensus in Dynamic Networks](https://arxiv.org/abs/2610.11805)
*Zeremonienmeister Berber Aab,Darya Melnyk,Stefan Schmid*

Main category: cs.DC

TL;DR: 该论文研究动态网络中的多维渐近一致（asymptotic agreement）问题，给出非分裂（non-split）网络模型下收缩率的新上界 sqrt(2d/(3d+1))（d→∞ 时趋于 sqrt(2/3)≈0.816），并首次给出多维无记忆匿名确定性算法的下界 2/3（d≥8），单轮情形下下界 sqrt((2d-2)/(3d+7)) 趋于 sqrt(2/3)，表明 BallMidpoint 策略在单轮意义下渐近最优。


<details>
  <summary>Details</summary>
Motivation: 动态网络中节点需在对抗式拓扑变化下就 d 维向量输入达成近似一致，且结果必须保持在所有输入的凸包内。非分裂网络模型下各节点凸包无公共交集、仅两两相交，使得已有的 all-to-all 模型结论无法直接沿用；此前最优上界为 MidExtremes 算法的 sqrt(7/8)≈0.935，而单维下界 1/2 在高维是否紧致未知。论文旨在收紧高维收缩率的上下界，厘清维度 d 对协议收敛速度的本质影响。

Method: 1) 将最初为 all-to-all 通信模型设计的 BallMidpoint 算法（节点取接收向量最小包围球的中点）适配到 non-split 动态网络模型，用于推导上界；2) 针对无坐标、无记忆、匿名、确定性算法，构造多维下界证明，覆盖有限 n 与无限 n 两种情形；3) 单独分析单轮（one-round）收缩，推导与 d 相关的下界以判定 BallMidpoint 的最优性。

Result: 上界：non-split 动态网络中收缩率 ≤ sqrt(2d/(3d+1))，d→∞ 时趋于 sqrt(2/3)≈0.816，优于此前 sqrt(7/8)≈0.935；该值严格劣于 all-to-all 容错近似一致中的 sqrt(1/2)≈0.707，原因是非分裂模型下凸包仅有两两相交而非公共交集。下界：首次给出多维下界 2/3（d≥8，有限 n），说明 d=1、n≥3 时的 1/2 下界在高维下不紧；n 无限时下界扩展为 sqrt((1/2)·d/(d+1))，d→∞ 收敛到 sqrt(1/2)。单轮下界为 sqrt((2d-2)/(3d+7))，d→∞ 收敛至 sqrt(2/3)，与上界渐近吻合，说明 BallMidpoint 在单轮意义下渐近最优。

Conclusion: 论文建立了多维渐近一致问题收缩率的维度相关刻画：上界 sqrt(2d/(3d+1)) 与单轮下界 sqrt((2d-2)/(3d+7)) 在 d→∞ 时共同趋于 sqrt(2/3)，证明 BallMidpoint 单轮渐近最优；同时首次证明 d≥8 时多维下界升至 2/3，推翻单维 1/2 下界的高维紧致性，并揭示 non-split 与 all-to-all 模型在收缩率上的本质差距（0.816 vs 0.707）。

Abstract: This work studies the multidimensional asymptotic agreement problem in dynamic networks. We assume that nodes have $d$-dimensional inputs and need to converge arbitrarily close to each other's inputs while their vectors stay inside the convex hull of all inputs.

To this end, we adapt the BallMidpoint algorithm (Melnyk, 2026) recently introduced for the all-to-all communication model. This algorithm lets the nodes choose the midpoint of the smallest enclosing ball of the received vectors. This bound is strictly worse than the $\sqrt{1/2}\approx 0.707$ contraction rate for fault-tolerant approximate agreement in all-to-all communication networks because the convex hulls of the nodes do not have a common intersection, and only intersect pairwise.
