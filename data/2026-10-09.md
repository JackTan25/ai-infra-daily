### [1] [IAPRepair: In-Network Aggregation Enhanced Proactive Repair for Erasure-Coded Storage System](https://arxiv.org/abs/2610.11114)

Main category: cs.DC

<details>
  <summary>Details</summary>
Motivation: 纠删码存储以远低于全复制的开销提供容错，但修复丢失或高风险数据块需要大量跨节点传输。现有方案存在两类割裂：反应式修复只在故障发生后才启动，缺乏提前缓解窗口；主动式修复虽可在故障前迁移数据，却通常把迁移、重建与网络聚合当作松耦合的独立操作，导致接收端瓶颈、可用带宽异构以及可编程交换机状态受限持续压制修复并行度。

Existing reactive repair schemes start only after a failure, while proactive schemes can move data before failure but commonly treat migration, reconstruction, and network aggregation as loosely coupled operations. The results demonstrate that coordinating proactive repair decisions with in-network processing is an effective way to improve repair efficiency under bandwidth heterogeneity.

### [2] [Zepp: Accelerating Distributed MoE Serving under Relaxed Balance Constraints](https://arxiv.org/abs/2610.11158)

Main category: cs.DC

TL;DR: Zepp 将负载均衡从优化目标降格为物理资源(GPU/NIC)上的简化约束,转而直接优化分布式 MoE 服务中的瓶颈通信,在 placement、routing、execution 三个层面渐进式协同优化,对 7 个 SOTA MoE 服务系统取得最高 6.68× 的 MoE 层加速、几何平均 1.86× 加速。


<details>
  <summary>Details</summary>

Method: 1) 问题重构:把均衡视为约束(对 GPU 与 NIC 等物理资源的简化均衡约束),把瓶颈通信(inter-node all-to-all / token 通信)作为真正的直接优化目标。2) 三层渐进优化:(a) placement 阶段在 GPU 约束下放置专家副本,减少跨节点 token 通信量;(b) routing 阶段在 NIC 约束下通过 split 与 merge 原语重塑通信流,压低链路瓶颈;(c) execution 阶段对专家计算做划分与调度,以 overlap 上述通信。3) 动态自适应:每次迭代联合协调计算、token 通信与专家权重的搬运(expert-weight movement),从而在动态负载下持续追踪最高效执行,而非单一维度的均衡解。4) 完整实现并对比 7 个 SOTA MoE 服务系统。

Yet skewed expert workloads create imbalance across computation, communication, and memory, making load balancing a central optimization objective in distributed MoE serving. We observe that balance is not free: operations introduced to balance one dimension can themselves be expensive or imbalanced. This motivates us to rethink balance as a constraint rather than an optimization objective. We present Zepp, which directly optimizes the bottleneck communication in distributed MoE serving subject to simplified balance constraints on physical resources, i.e., GPUs and NICs. Zepp progressively optimizes inter-node communication across placement, routing, and execution. It first places expert replicas to reduce token communication under GPU constraints, then reshapes communication flows through split and merge primitives under NIC constraints, and finally partitions and schedules ex- pert computation to overlap the resulting communication. To adapt to dynamic workloads, Zepp jointly coordinates computation, token communication, and expert-weight movement at each iteration. Together, these designs allow Zepp to pursue the most efficient execution rather than a single-dimension balanced one. We implement Zepp and evaluate it against 7 state-of-the-art MoE serving systems, achieving up to 6.68$\times$ MoE layer speedup and a geometric mean speedup of 1.86$\times$ over the fastest competing baseline.

### [3] [PageWeaver: KV-Guided Query Unions for Sparse Attention](https://arxiv.org/abs/2610.11201)
*Zhiyuan Li,Zihan Li,Zefang Yuan,Lei Wang,Hao Wang*

Main category: cs.DC

TL;DR: PageWeaver 提出一种基于"选定页亲和性"(selected-page affinity)的查询分组执行设计：在保持每个 query 原始稀疏 support 与完整输出所有权不变的前提下，将有共同 KV 页的 query 聚成组，以摊销页加载并填充 Tensor Core tile。它用一个有界 GPU 搜索生成 query ID 序列，再由 ID-aware 双 CTA kernel 直接消费这些 ID，从而避免物化重排后的 Q 张量或跨页部分输出。在 FP8 KV、H200 上，Union8 实现相对 FlashInfer 路径 1.70x 几何平均完整调用加速；在线重分组在 5 个 64K 上下文下再降 3.26–7.66% 延迟；整模型 prefill 吞吐高于原生路径 7.88–14.36%，但增量收益随上下文长度与硬件变化而衰减（32K/64K 中位增益仅 0.47–0.73%，8K 出现回退）。


<details>
  <summary>Details</summary>

Method: 论文以"执行分组复用"为核心：（1）以选定页亲和性做 query 分组——组内 query 的页集合并集共享页加载，但每个 query 仍只在其原始 support 上计算，输出归属完整；组大小与页并集规模有界，避免并集膨胀抵消收益；（2）用有界 GPU 搜索产出 query ID（重排索引），只搬运 ID 而非张量数据；（3）ID-aware 双 CTA kernel 直接按 ID 消费查询，不物化重排后的 Q 张量、也不产生跨页 partial output，从而剔除额外的拷贝与中间归约；（4）额外实现一个直接 KV 页并集的对照设计（Union 实现），用于剖析非局部复用与归约成本之间的权衡；（5）支持在线重分组(online regrouping)，量化其相对静态分组的增量收益；（6）全流程 FP8 KV。

Abstract: Dynamic sparse attention limits the KV pages selected by each query, but a small support does not necessarily yield efficient GPU work. Query unions share page loads and populate Tensor Core tiles; their cost depends on which queries are grouped together. We present PageWeaver, an execution design that uses selected-page affinity to assemble query groups while preserving each query's original support and complete output ownership. A bounded GPU search produces query IDs, and an ID-aware two-CTA kernel consumes them without materializing reordered Q tensors or cross-page partial outputs. Online regrouping further lowers latency by 3.26-7.66% on five selected 64K-context captures. Whole-model prefill throughput is 7.88-14.36% above the tested native path; the incremental regrouping benefit is smaller, with observed median gains of 0.47-0.73% at 32K/64K and regressions at 8K. A B300 comparison identifies cases where preparation cost and a stronger native kernel remove the advantage. These results separate execution-group reuse from the complete cost of exploiting it online.

### [5] [New Contraction Bounds for Multidimensional Asymptotic Consensus in Dynamic Networks](https://arxiv.org/abs/2610.11805)

<details>
  <summary>Details</summary>

Method: 1) 上界：把为 all-to-all 通信模型设计的 BallMidpoint 算法（Melnyk, 2026）适配到 non-split 动态网络，节点在每轮取所收到向量最小包围球（smallest enclosing ball）的中点作为新状态。2) 下界：针对坐标无关（coordinate-free）、无记忆（memoryless）、匿名（anonymous）、确定性算法，在 non-split 网络中构造对抗性执行（adversarial execution），分析维度 d 对收缩因子的影响。3) 进一步针对无限节点数 n→∞ 的扩展下界，以及单轮（single-round）最优性分析。

Conclusion: 论文将多维动态网络渐近一致性的收缩率上下界显著收紧：上界从 0.935 降至约 0.816，并首次给出高维非平凡下界 2/3，同时通过单轮下界 √((2d−2)/(3d+7)) 证明 BallMidpoint 渐近最优。核心结论是维度 d 越高收缩越难（下界上升），但固定算法族下界随 n→∞ 回落至 √(1/2)，揭示了维度与网络规模对一致性收敛速率的耦合关系。方法完全属于分布式算法理论（收缩率/凸包几何），不涉及模型训练、推理或系统实现。

  We present a new upper bound of $\sqrt{2d/(3d+1)}$ on the contraction rate of asymptotic agreement in the non-split network model, where $d$ is the dimension of the input and $\sqrt{2d/(3d+1)}\rightarrow \sqrt{2/3}\approx 0.816$ for $d\rightarrow\infty$. To this end, we adapt the BallMidpoint algorithm (Melnyk, 2026) recently introduced for the all-to-all communication model. This algorithm lets the nodes choose the midpoint of the smallest enclosing ball of the received vectors. This result shows that the previously best-known lower bound of $1/2$ on the contraction rate for $n\ge 3$ and $d=1$ is not tight in higher dimensions. We further show that for a single round, the one-round contraction is at least $\sqrt{\frac{2d-2}{3d+7}}$, which converges to $\sqrt{2/3}$ for $d\rightarrow\infty$, showing that the BallMidpoint strategy is asymptotically optimal for one round.
