### [1] [Minions: A Dynamic and Distributed Virtual GPU Cloud Built on Idle Apple Silicon Devices](https://arxiv.org/abs/2610.12970)

Main category: cs.DC

TL;DR: Minions 是一个动态分布式虚拟 GPU 云系统，将 macOS Apple Silicon 设备的空闲 GPU 聚合成推理资源池，在集中式 GPU 受限场景下提供容错的弹性推理能力。


<details>
  <summary>Details</summary>
Motivation: 集中式 GPU 基础设施成本高、弹性差、排队久；而大量 Apple Silicon macOS 设备（M 系列统一内存架构）在日常使用中 GPU 长期闲置，算力被浪费。论文试图在不新增 GPU 采购的前提下，把闲置端侧 GPU 转化为可用推理算力。

Method: 构建分布式虚拟 GPU 云：跨多台 macOS 设备聚合闲置 Apple Silicon GPU，提供统一的 GPU 推理任务执行、调度与故障容错机制，并追求高效资源利用。摘要未披露具体调度算法、任务切分粒度、网络传输路径（如 Thunderbolt/以太网）以及容错实现细节。

At the same time, modern Apple Silicon-based macOS devices are equipped with powerful GPUs that remain largely idle during normal usage. This paper presents Minions, a dynamic and distributed virtual GPU cloud that aggregates idle Apple Silicon GPUs across macOS devices to execute large-scale machine learning inference workloads. Minions enables teams to leverage existing hardware without requiring additional GPU procurement. The system provides flexible GPU inference task execution, fault tolerance, and efficient resource utilization. Our experience shows that idle macOS devices can be transformed into a practical distributed GPU inference platform in environments where centralized GPU resources are constrained.

### [2] [SlackSwap: Bandwidth-Aware Activation Swapping and Recomputation for Memory-Efficient DNN Training](https://arxiv.org/abs/2610.13003)
*Hui Feng,Xun Zhou,Yuxin Wang*

Main category: cs.DC

TL;DR: SlackSwap 将 host-link 传输时间视为显式资源预算，用一次 profile 迭代生成 activation offload/recompute 联合计划，在 A100 上以一半 activation 显存保留 96-100% 无显存限制吞吐，优于 vDNN/SuperNeurons/SwapAdvisor/block checkpointing。


<details>
  <summary>Details</summary>
Motivation: 训练峰值算力与 host-link 带宽的失衡：Titan X→H100 峰值训练吞吐提升 141x，而 host-link 带宽仅提升 3.9x。2015 年 Titan X 上 PCIe 足以在 forward 阶段 offload 全部 VGG-16 activation 的均衡已不复存在。在 A100 上，对论文研究的 transformer 模型，host link 只能隐藏 11-38% activation 的传输。既有 swapping 方法（vDNN、SuperNeurons、SwapAdvisor）按显存需求决定 offload 张量，不显式遵守可用链路时间预算，导致 transfer-induced stall；block checkpointing 则相反，使 host link 利用不足。

Method: 把 host-link 时间当作显式资源预算。仅用一次 profiled iteration：先将 forward-pass 链路预算分配给重算代价最高的张量（优先 offload 昂贵重算者），再用重算最便宜的张量补齐剩余显存缺口；调度上采用 FIFO offload + earliest-deadline-first (EDF) prefetch，且不插入逐层同步屏障。

Result: 在 A100 上对 BERT-Large、GPT-2 XL 和 Llama-7B 风格模型做 trace-driven 仿真：SlackSwap 在仅用一半 activation 显存的情况下保留 96-100% 的 unlimited-memory GPU 吞吐，达到最佳 baseline 的 1.10-1.11x 吞吐；其计划与 6,600-14,000 个候选方案上的遗传搜索差距在 0.5% 以内，生成耗时不到 0.4 秒。

Conclusion: 核心贡献是把 activation memory 管理从"按显存需求 offload"重构为"按链路时间预算分配"的联合 offload/recompute 规划问题，并给出廉价（<0.4s）、近最优（距遗传搜索 ≤0.5%）的启发式规划器与无屏障调度。工程影响：在当代加速器上 host-link/算力比持续恶化（含 PCIe Gen5/6、NVLink-C2C、Grace-Hopper 等），该方法可直接作为 activation memory manager 集成进训练框架/编译器（如 PyTorch FSDP 类 activation offload、XLA/TVM 类图级调度），以一半 activation 显存换取接近峰值吞吐，缓解显存墙并提升大模型训练的可扩展性与成本效率。

Abstract: Swapping saved activations to host memory once enabled GPUs to train models that exceeded their device-memory capacity when compute throughput and host-link bandwidth were roughly balanced. For example, on a 2015 Titan X, PCIe bandwidth was sufficient to offload all VGG-16 activations during the forward pass. This balance no longer holds. From the Titan X to the H100, peak training throughput increased by 141x, whereas host-link bandwidth improved by only 3.9x. On an A100, the host link can hide transfers for only 11-38% of the activations in the transformer models we study. Existing swapping approaches, such as vDNN, SuperNeurons, and SwapAdvisor, offload tensors according to memory requirements without explicitly respecting the available link-time budget, resulting in transfer-induced stalls; block checkpointing, in contrast, leaves the host link underutilized. We present SlackSwap, which treats host-link time as an explicit resource budget. Using a single profiled iteration, SlackSwap allocates the forward-pass link budget to tensors that are most expensive to recompute, resolves the remaining memory deficit by recomputing the least expensive tensors, and schedules FIFO offloads and earliest-deadline-first prefetches without per-layer synchronization barriers. In trace-driven simulations of BERT-Large, GPT-2 XL, and a Llama-7B-style model on an A100, SlackSwap retains 96-100% of unlimited-memory GPU throughput while using half the activation memory, achieving 1.10-1.11x the throughput of the best baseline. Its plans are within 0.5% of a genetic search over 6,600-14,000 candidate plans, while requiring less than 0.4 seconds to generate.

### [3] [Execution-Feasible Dispatch of LLM Pre-training Loads for Renewable-Dominant AI Data Centers](https://arxiv.org/abs/2610.13047)

Method: 1) 场景：月球与火星的更新经一个共享缓冲区的中继转发至地球，接触驱动（contact-driven）动态。2) 度量：定义目的端信息新鲜度的"超额年龄" Δ_i^e(t)=[Δ_i(t)-d_i(t)]^+，其中 Δ_i(t) 为源 i 的AoI，d_i(t) 为源相关时延基线，从而把"物理传输必然引入的时延"从惩罚中剔除，只惩罚超出基线的信息陈旧。3) 目标：基于该度量定义目标导向损失，支持源相关的非线性惩罚，以按任务重要性排序（高优先级源获得更陡的惩罚）。4) 建模：将中继控制形式化为约束半马尔可夫决策过程（CSMDP），约束来源于存储/接触窗口等可行性条件。5) 求解：使用带掩码的拉格朗日PPO（masked Lagrangian PPO），其中可行性感知动作掩码将动作限制在"能在剩余接触窗口内完成传输"的束上，拉格朗日乘子处理约束。6) 评估：在DTNSim上进行仿真，与FIFO等基线调度器比较年龄效用与流间公平性。

Result: DTNSim仿真结果显示，所提框架相比基线调度器（如FIFO）在基于年龄的效用和流间公平性上均有改善；框架能够在中继侧同时优化束调度、丢弃与流控，并在显式考虑异构源间公平性的情况下适应接触驱动的动态。

Conclusion: 论文的贡献在于把深空中继的束管理从"排队论式"的FIFO/优先级规则，推进到"目标导向 + 约束RL"的可学习闭环：以超额年龄这一新颖度量把AoI与任务相关性解耦，用CSMDP刻画接触窗口与缓冲约束，以动作掩码+拉格朗日PPO在保证可行性的同时处理约束与公平。工程意义上，它给行星际中继/DTN网关的调度器提供了一个可插拔的、按任务价值分配稀缺接触资源的策略学习范式；但其结果目前仅来自DTNSim，离在真实Bundle Protocol栈上部署仍有差距。

Abstract: Deep-space communications operate under intermittent connectivity, long propagation delays, and relay storage constraints. In such networks, the Bundle Protocol enables store-carry-forward communication, requiring relay nodes to manage limited storage and scarce contact opportunities. Relay-side scheduling and dropping decisions are inherently goal-oriented: transmission resources should be allocated to bundles most valuable to downstream mission objectives. Conventional schedulers, such as FIFO, do not explicitly optimize task utility and may provide unfair service across heterogeneous planetary sources. This paper presents a closed-loop modeling and learning framework for relay-side bundle and flow management in a contact-driven deep-space network, where lunar and Martian updates are forwarded through a shared-buffer relay to Earth. We quantify destination-side information freshness using excess age $Δ_i^e(t)=[Δ_i(t)-d_i(t)]^+$, where $Δ_i(t)$ denotes the Age of Information of source $i$ and $d_i(t)$ is a source-dependent delay baseline. Based on this metric, we define a goal-oriented loss that supports source-dependent nonlinear penalties, allowing prioritization according to mission relevance. We formulate relay control as a constrained semi-Markov decision process (CSMDP) and solve it using masked Lagrangian Proximal Policy Optimization (PPO). Feasibility-aware action masking restricts transmissions to bundles that can complete within the remaining contact window. DTNSim simulations indicate improved age-based utility and inter-flow fairness compared with baseline schedulers. The proposed framework jointly optimizes relay-side bundle scheduling, dropping, and flow control under contact-driven dynamics with explicit fairness considerations across heterogeneous sources.
