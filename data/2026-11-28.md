### [1] [Conditional Work Bounds and Timing Evidence for an Industrial NDT Scan Matcher: Cross-Language Work-Trace Conformance](https://arxiv.org/abs/2611.33159)

<details>
  <summary>Details</summary>

Method: 核心机制是受限柔性路由：每个 token 的 Top-p 专家强制保留（质量锚点），剩余 k-p 个槽位从 Top-L（L>k）候选集合中按负载挑选。Prefill 路径为每个 rank 计算"价格"（负载惩罚项），以价格驱动 token 向低负载 rank 柔性迁移，降低 max per-rank token count；Decode 路径在保证每 token 约束的前提下主动"关闭"最忙 rank 上的部分专家，降低 max active-expert count，从而减少该 rank 的权重读取量。实现上：kernel 与模型执行重叠（overlap），复用现有 DeepEP 通信通道传输元数据（不新增集合通信），在 SGLang 与 DeepEP 中完成端到端集成。

Meanwhile, Expert Parallelism (EP) has been widely adopted in large Mixture-of-Experts (MoE) model serving. However, load imbalance still slows down MoE inference because each layer must wait for the busiest EP rank. The main source of latency differs between prefill and decode. Prefill is compute-bound, and its MoE layers' latency is determined by the maximum token count of the busiest rank. The quality cost is below one percentage point.
