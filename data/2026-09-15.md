### [1] [A Lifecycle Cost Analysis of Smart-Contract-Coordinated Federated Learning Marketplaces](https://arxiv.org/abs/2609.13170)
*Luan Mantegazine,Luiza Leidemer,Claudio Geyer*

Main category: cs.DC

  <summary>Details</summary>

### [2] [Dynamic HBM Repartitioning for Multi-Turn MoE Serving](https://arxiv.org/abs/2609.13537)
*Jinpyo Kim,Mingi Kwon,Younghoon Min,Jongryool Kim,Jishen Zhao*

Main category: cs.DC

TL;DR: VAMP 是一个 MoE 推理服务框架，通过在运行时动态调整 GPU HBM 中“专家权重区”与“KV Cache 区”的边界来缓解长多轮会话的 KV 状态压力：当 KV 分配失败时，它在三类代价（专家权重从主机内存暂存、驱逐可复用前缀导致重 prefill、抢占并重调度请求）之间做代价估计，并选择代价最低者；当选中的是卸载专家权重时，借助 CUDA VMM 页重映射把一段有界专家权重区域转为 KV 容量，无需拷贝驻留 KV 数据。在 vLLM 中实现、Qwen3-Next-80B 上，SWE-bench 2103 轮 agent 负载五次重放中，15% 最大专家卸载率下 TTFT p90 从 26.1s 降至 1.10s（23.6×），吞吐 +20.7%，TPOT 上升 31.1%。


<details>
  <summary>Details</summary>
Motivation: MoE 模型的专家权重占据大部分 GPU HBM，但每个 token 只激活稀疏子集，专家权重利用率在时间维度上很低。而长多轮请求会累积可复用的 KV state，超出固定的 GPU KV-cache 分配后，现有服务系统只能驱逐可复用前缀（导致重复 prefill）或抢占请求。权重与 KV cache 之间的静态内存划分使得二者无法互补：一边是长期闲置的专家权重容量，另一边是不断增长的复用状态。核心动机是打破这个静态边界，让空闲的专家内存能在需要时服务于 KV 复用。

Method: 1) 运行时 HBM 边界调整：把专家权重区与 KV cache 区的划分从静态改为动态。2) 代价模型驱动的决策：当一次 KV 分配无法满足时，估计三种备选方案的未来工作量——(a) 从 host memory 暂存/换入专家权重、(b) 驱逐缓存前缀并可能触发 re-prefill、(c) 抢占并重调度请求——并选择估计惩罚最小者。3) 有界转换：仅在决策最优时，将一段“有界”的专家权重区域转换为 KV cache 容量，避免专家路径性能无限退化（因此有 15% 最大卸载率这一上限）。4) 零拷贝转换：用 CUDA Virtual Memory Management（VMM）的物理页重映射把该区域重新映射为 KV 使用，驻留 KV 数据无需拷贝。5) 实现于 vLLM，面向 MoE 服务引擎。

Result: 在 Qwen3-Next-80B 上，针对录制的和受控的多轮负载：录制 SWE-bench agent 负载共 2,103 轮、五次重放，VAMP 在 15% 最大专家卸载率下把 TTFT p90 从 26.1 s 降到 1.10 s（23.6×），请求吞吐相对未修改 vLLM 提升 20.7%，代价是 TPOT 增加 31.1%。

Once this state exceeds a fixed GPU KV-cache allocation, serving systems evict reusable prefixes, repeat prefill work, and may preempt requests. This pressure is particularly acute for Mixture-of-Experts (MoE) models: their expert weights occupy most GPU high-bandwidth memory (HBM), even though each token activates only a sparse subset of experts. A static boundary between weights and the KV cache prevents serving systems from using expert memory to preserve reusable state as conversations grow.

When a KV allocation cannot be satisfied, VAMP compares the estimated future work of three alternatives: staging expert weights from host memory, evicting cached prefixes that may require re-prefill, or preempting and rescheduling requests. It then converts a bounded expert-weight region into KV-cache capacity when that action has the lowest estimated penalty. CUDA Virtual Memory Management page remapping performs this conversion without copying resident KV data.

Across five replays of a recorded 2,103-turn SWE-bench agent workload, VAMP with a 15% maximum expert-offloading ratio reduces time-to-first-token (TTFT) p90 from 26.1 s to 1.10 s (23.6 times) and increases request throughput by 20.7% relative to unmodified vLLM, while increasing time per output token (TPOT) by 31.1%.

TL;DR: 本文重新审视 Max-Host Dragonfly+ 拓扑 2:1 期望超订比的原始证明，指出其仅覆盖部分置换流量、且证明中存在两处相互抵消的错误，并隐含使用了一个未经论证的关键假设。作者将该结论推广到更一般的置换模式（仅要求主机收发不超过线速），给出高概率界，并通过实验表明全局层布线在非期望情形下确实影响超订率，可带来不超过 7% 的加速。

Motivation: Dragonfly/Dragonfly+ 是大规模互连网络的重要拓扑，其 2:1 超订比结论被广泛引用作为设计依据。但原始证明的适用范围与严谨性存疑：仅覆盖 sender/receiver 分布受限的置换子集，且逻辑上存在错误与未论证假设。若不澄清，工程上可能误用该结论来指导全局层布线设计，而实际上全局 wiring 在非期望/最坏情形下会影响性能。

Method: 1) 对原证明做形式化审查，指出两处相互抵消的错误，以及"离开 indirect group 的流量仍可分散到几乎所有全局出链路"这一隐含假设缺乏依据；2) 放宽假设，仅要求每台主机收发不超过线速，重新推导并证明 2:1 期望比在包括任意置换在内的更大模式集合上成立；3) 去掉期望假设，针对小 radix（≤8）推导以高概率成立的超订比界；4) 修改线速约束以获得任意模式下的期望 FCT 近似界；5) 通过实验比较不同全局层 wiring 与原始默认布线的性能。

Result: 证明 2:1 期望超订比在更广的模式集合（含任意置换）上成立；原结论仅在受限置换子集上被正确证明，且是两处错误相互抵消的偶然结果。给出小 radix（≤8）下以高概率成立的超订比界。实验发现：在期望意义下全局层 wiring 不影响超订率，但在一般情形下其影响显著；存在优于原始默认全局布线的拓扑，radix≤8 时加速不超过 7%。

Conclusion: 该工作从理论严谨性与适用范围两方面修正并拓展了 Dragonfly+ 超订比分析，并揭示全局层布线在非期望情形下的实际影响。对数据中心/超算互连设计者而言，意味着 2:1 结论虽更普适但仍需谨慎引用，全局布线优化可在小 radix 场景带来可测收益，为拓扑与路由协同设计提供依据。

Abstract: The Max-Host Dragonfly+ topology's original paper proves that there is a 2:1 worst-case oversubscription ratio in expectation for the permutation traffic pattern. We show that the proof only covers a subset of permutation patterns, specifically those in which all host pairs are in different groups, and for any receiver group there are at least two sending hosts in distinct groups. The proof contains two mistakes that cancel out to produce the correct result. Furthermore, the proof implicitly uses an important observation without a backing argument: traffic leaving an indirect group, now forced to follow min-cost paths to receiver groups, can still be split across almost all outgoing global links, in contrast with splitting traffic from a sender group that can naturally select any outgoing group.
  We prove that the 2:1 ratio holds in expectation for a larger set of patterns, including any permutation. We only need to know that any host sends and receives at most line rate traffic. This constraint can be altered to obtain approximations for expected FCT bounds on any pattern. We also attack the oversubscription problem without the expectation assumption, and find bounds that hold with high probability on permutations for small switch radixes.
  While in expectation the global layer wiring doesn't affect the oversubscription rate, we experimentally find that it matters in the general case. We find topologies that obtain visible speedups against the default global wiring from the original paper, under $7\%$ for radixes at most $8$.
